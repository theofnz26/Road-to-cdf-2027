# Road to CDF 2027

Projet réalisé dans le cadre de la formation Développeur Web et Web Mobile.

Objectif :
Suivre ma progression vers le Championnat de France Yu-Gi-Oh! 2027 grâce à une interface web simple comportant :

- Une page d'accueil
- Une roadmap de progression
- Un calendrier d'événements

Technologies utilisées :

- HTML5
- CSS3
- JavaScript
